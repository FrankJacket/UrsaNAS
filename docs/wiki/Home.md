# Welcome to UrsaNAS

UrsaNAS turns a computer into a network storage box ("NAS") that your other devices — phones, laptops, TVs, media players — can use to store and read files over your home network. Everything is managed from a web page, so you never need to type commands.

This wiki is written for the person running the NAS, not for a technician. It explains what each page of the interface does and why you'd use it, without going into the technical details behind it.

## Where to start

New to UrsaNAS? Read **[Getting Started](Getting-Started)** first: it covers installing UrsaNAS and signing in for the first time.

## What's where

The interface is organised into a few areas, listed here in the order you'll usually use them:

| Area | What it's for |
|---|---|
| **[Storage](Storage)** | Preparing the disks that hold your files, and organising them into pools and folders. |
| **[Sharing Files](Sharing-Files)** | Making a folder available to your other devices over the network. |
| **[File Manager](File-Manager)** | Browsing, moving and organising your files from the browser itself. |
| **[Accounts](Accounts)** | Who can sign in to this interface, and who can access your shared folders. |
| **[Backups](Backups)** | Copying your files to an external disk, automatically. |
| **[Remote Storage](Remote-Storage)** | Connecting the NAS to another server or to an online storage service. |
| **[Virtual Machines](Virtual-Machines)** | Running a full extra computer (with its own operating system) on the NAS. |
| **[Docker Apps](Docker-Apps)** | Running small ready-made applications on the NAS. |
| **[Network](Network)** | Checking and adjusting how the NAS connects to your network. |
| **[Alerts and Activity](Alerts-and-Activity)** | Being notified when something needs attention, and seeing what changed recently. |
| **[System Settings](System-Settings)** | Keeping UrsaNAS itself up to date, and backing up its configuration. |

If something isn't working as expected, see **[Troubleshooting](Troubleshooting)**.

## The first screen: Dashboard

The **Dashboard** is the first page you see after signing in. It gives you an at-a-glance health check of the machine itself: how long it's been running, how hot the processor is, how much memory and storage space is used. You don't need to act on anything here unless a number looks unusually high — it's just a quick way to confirm the NAS is healthy.

## Restarting or shutting down

The power button in the top-right corner of every page lets you **Restart** or **Shut down** the NAS. Use shutdown before unplugging the machine or moving it.
