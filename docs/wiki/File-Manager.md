# File Manager

The **File Manager** lets you browse your files directly from the web interface, without needing to connect from another device first. It's handy for a quick look, for moving files around, or for setting permissions on a specific folder.

## What you can browse

Use the **Source** selector at the top to switch between:

- **Shares** — the folders you've shared (see [Sharing Files](Sharing-Files)).
- **Mounted drives** — disks plugged into the NAS that aren't part of a share.
- **Remote** — storage connected from [Remote Storage](Remote-Storage).

## What you can do

Select a file or folder, then use the toolbar above the list:

- **New folder** — create a sub-folder.
- **Rename**, **Move**, **Copy**, **Delete** — the usual file operations.
- **Permissions** — open the permissions of the selected folder; see **[Advanced Permissions](Advanced-Permissions)**.

Any folder marked **"Inheritance off"** has its own permissions, separate from its parent — a quick way to spot where access differs from the rest of a share.
